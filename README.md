# UBS5 GNT Text-Fabric

This Github repository houses the [Text-Fabric](https://github.com/annotation/text-fabric) representation of the UBS5 Greek New Testament text. It was converted using the Emdros database of the UBS5 encoded by Ulik Sandborg-Petersen and converted to TF by Saulo de Oliveira Cantanhêde.

### Documentation

The feature documentation can be found [here](https://github.com/saulocantanhede/UBSGNT5/blob/main/docs/README.md). They have the similar nomeclature to the morphological and syntatical features used in the Nestle 1904 GNT dataset. More information can be checked [here](https://centerblc.github.io/N1904/).
